# Publish the program website on GitHub Pages

After uploading this repository, open Settings → Pages. Under Build and deployment,
select Deploy from a branch, then choose main and /docs, and Save.
The website has a catalogue and six individual guides, each with two small plot
previews linked to full-size images. The download ZIP contains the six programs,
source, three regional CSV files, sample plots, and run/build instructions.

To update data, replace the relevant regional CSV and regenerate the plots. The
website previews and download ZIP are snapshots and should be regenerated too.
The site does not download data or run the desktop applications in the browser.
