About these charts

These are downloadable desktop tools, with saved plots shown as examples. They use the supplied CSV data and average values. Update the local CSV copies to generate charts for newer seasons; the website does not provide a live data feed.

C# programs use Windows .NET Framework. Python packages include dependency instructions. The original OneDrive programs remain separate from the published copies.
