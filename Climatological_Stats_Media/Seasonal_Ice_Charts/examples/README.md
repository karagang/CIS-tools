# Chart thumbnails

These thumbnails were resized from the real PNG output files included with the two editions; they are not mockups. See the [chart gallery](../) for clickable comparisons.

- `python-*-thumb.png`: Matplotlib output from the supplied Python programs.
- `csharp-*-thumb.png`: native C# output from the standalone applications.
- Lake-named thumbnails: recent-years C# charts for all six lake areas.

All examples use the supplied CSV snapshots, start year 1973, and latest CSV year 2026. The full-size files are in each edition's lake-specific `output` folder. Combined images are 1800 × 2700 pixels; individual images are 1800 × 1050 pixels, all at 150 DPI.

To regenerate the full images, run the chosen lake's program and accept both defaults. For C#, `*_IceCharts.exe --defaults` runs without prompts. The [Python instructions](../Python/) and [C# guide](../CSharp/) explain installation and usage.
