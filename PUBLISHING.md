# GitHub Pages publishing

Publish from the main branch and the /docs folder in Settings → Pages.

The website covers East Coast and Great Lakes programs: 14 C# entries and
9 Python guides, with small plot previews and complete download packages.
Source snapshots are browsable in the regional folders, OtherCSharpSources,
and PythonSources. ZIP downloads preserve each program’s runtime/build layout.

CSV data and example charts are snapshots. When programs or inputs change,
regenerate the relevant outputs, thumbnails, and ZIPs before republishing.
